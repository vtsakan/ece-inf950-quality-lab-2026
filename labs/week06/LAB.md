## Ένα black-box test στο StudyRoom

Παράδειγμα της μορφής, για κανόνα που **δεν** ανήκει στα ερωτήματα (ωράριο Σαββάτου, ΚΡ1):

```python
# studyroom/tests/blackbox/test_kr01_saturday.py
from datetime import datetime

import pytest

from studyroom import BookingError, create_booking

SAT = (2026, 11, 7)          # Σάββατο· το fixture now είναι Τρίτη 3/11/2026 10:00


@pytest.mark.parametrize("hour, hours, ok", [
    (9, 1, False),    # πριν το άνοιγμα
    (10, 1, True),    # πρώτη ώρα
    (17, 1, True),    # τελευταία ώρα, λήγει 18:00
    (17, 2, False),   # θα έληγε 19:00
    (18, 1, False),   # μετά το κλείσιμο
])
def test_saturday_hours(now, hour, hours, ok):
    start = datetime(*SAT, hour, 0)
    if ok:
        assert create_booking("1001", "Α-1", start, hours, now=now).status == "active"
    else:
        with pytest.raises(BookingError):
            create_booking("1001", "Α-1", start, hours, now=now)
```

Για τις υπόλοιπες ενέργειες: `cancel_booking(booking_id, student_id, now=…)`, `check_in(booking_id, person_id, now=…)`, `sweep_no_shows(now=…)`. Εξεταστική ορίζετε με `rules.EXAM_PERIODS.append((date(…), date(…)))`· το conftest την καθαρίζει πριν από κάθε test. Ο αποκλεισμός ενός φοιτητή φαίνεται στο `store.get_student(id).blocked_until`.

## Χρήσιμες επιλογές

- `pytest -v`: ένα αποτέλεσμα ανά test case, με το ID του.
- `pytest -k "TC-BB-07"`: μόνο τα tests που ταιριάζουν.
- `pytest -rf`: σύνοψη των αποτυχιών στο τέλος.
- `pytest --junitxml=w06-results.xml`: τα αποτελέσματα σε αρχείο, για την Ενότητα 5.
- `pytest.param(..., marks=pytest.mark.xfail(reason="ελάττωμα INC-01", strict=True))`: test που αναμένεται να αποτύχει μέχρι να διορθωθεί το ελάττωμα. Το `strict=True` σάς ειδοποιεί όταν αρχίσει να περνά.

## Συχνά λάθη

- Αναμενόμενο αποτέλεσμα αντιγραμμένο από την έξοδο του κώδικα.
- Tests χωρίς ρητό `now`, που περνούν ή αποτυγχάνουν ανάλογα με την ώρα που τρέχουν.
- Ένα test που ελέγχει δύο κανόνες μαζί, οπότε η αποτυχία δεν λέει ποιος παραβιάστηκε. Στη FR-08 αυτό σημαίνει υποσύνολο κοντά στα 15 €.
- Μη έγκυρες μεταβάσεις που ελέγχουν μόνο την απόρριψη και όχι ότι η κατάσταση δεν άλλαξε.
- Διόρθωση του κώδικα. Αυτή την εβδομάδα τα ελαττώματα καταγράφονται, δεν διορθώνονται.
