# Εβδομάδα 8 · Σχέδιο και αναφορά unit testing · StudyRoom

> Πρότυπο αναφοράς: ISO/IEC/IEEE 29119-3. Χρησιμοποιούνται συντομευμένα το σχέδιο ελέγχου (test plan) για το επίπεδο μονάδων και η αναφορά ολοκλήρωσης ελέγχου (test completion report). Οι διαδικασίες ελέγχου (test procedures) είναι τα ίδια τα αρχεία pytest.

## Μέρος Α · Σχέδιο ελέγχου μονάδων

### Α.1 Εύρος

> Ποια modules, ποιες απαιτήσεις, τι εκτός (π.χ. HTTP layer).

### Α.2 Στρατηγική

| Στοιχείο | Απόφαση |
|---|---|
| Τεχνικές σχεδιασμού | Από τις Εβδομάδες 6–7 (αναφορά σε TC-BB-xx, TC-WB-xx) |
| Test doubles | Τι αντικαθίσταται (ρολόι, ταυτοποίηση, email) και με τι (stub, fake, mock) |
| Δεδομένα ελέγχου | Fixtures, factories |
| Κριτήρια ολοκλήρωσης | π.χ. κάλυψη διακλαδώσεων ≥ X% στα modules κανόνων, 0 αποτυχίες |
| Regression | Ποια tests τρέχουν σε κάθε αλλαγή |

### Α.3 Αναδιάρθρωση για ελεγξιμότητα

| Πρόβλημα ελεγξιμότητας | Τοποθεσία | Αλλαγή | Απαίτηση ελεγξιμότητας που ικανοποιείται |
