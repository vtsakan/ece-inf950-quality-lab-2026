# Εβδομάδα 12 · Προδιαγραφή quality gate και ροής CI · StudyRoom

> Πρότυπο αναφοράς: ISO/IEC 25040 (διεργασία αξιολόγησης ποιότητας προϊόντος: καθορισμός απαιτήσεων αξιολόγησης, προδιαγραφή αξιολόγησης με μέτρα και κριτήρια απόφασης, σχεδιασμός, εκτέλεση, ολοκλήρωση). Το quality gate αντιμετωπίζεται ως αυτοματοποιημένη αξιολόγηση που εκτελείται σε κάθε αλλαγή. Για τη ροή CI δεν υπάρχει διεθνές πρότυπο· η τεκμηρίωση ακολουθεί τη διάλεξη.

**Ομάδα:** [ονόματα, ΑΜ] · **Έκδοση:** w12 · **Αρχείο ροής:** `.github/workflows/[όνομα].yml`

## 1. Απαιτήσεις αξιολόγησης

> Τι πρέπει να ισχύει για να γίνει δεκτή μια αλλαγή, και ποιες απαιτήσεις ή κίνδυνοι το δικαιολογούν.

## 2. Προδιαγραφή του quality gate

| Κριτήριο | Μέτρο | Εργαλείο και εντολή | Κατώφλι (κριτήριο απόφασης) | Απαίτηση / κίνδυνος | Μπλοκάρει; |
|---|---|---|---|---|---|
| Όλα τα tests περνούν | Αποτυχίες | `pytest` | 0 | | Ναι |
| Κάλυψη διακλαδώσεων | % | `pytest --cov --cov-branch --cov-fail-under=X` | | | |
| Στατική ανάλυση | Ευρήματα ανά κατηγορία | `ruff check` | | | |
| Πολυπλοκότητα | Μέγιστη CC | `radon cc` | | | |
| Ασφάλεια | Ευρήματα υψηλής σοβαρότητας | `bandit` | | | |

> Αιτιολογήστε κάθε κατώφλι. Ένα κατώφλι χωρίς αιτιολόγηση είναι αυθαίρετο, και ένα πολύ αυστηρό κατώφλι οδηγεί σε παρακάμψεις.
